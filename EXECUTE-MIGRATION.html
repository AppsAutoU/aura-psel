🔧 Database Migration

Add nivel_ingles column to aura_jobs_candidatos table

⚠️ Important: This migration adds the nivel_ingles column to your database. Without this column, candidates cannot submit applications with their English level.

📋 Instructions

1
Open Supabase Dashboard

Go to Supabase SQL Editor

2
Copy the SQL below

Click the "Copy SQL" button to copy the migration query:

-- Add nivel_ingles column to aura_jobs_candidatos
ALTER TABLE aura_jobs_candidatos
ADD COLUMN IF NOT EXISTS nivel_ingles TEXT;

-- Add comment to the column
COMMENT ON COLUMN aura_jobs_candidatos.nivel_ingles IS
'Nível de inglês do candidato (Básico, Intermediário, Avançado, Fluente, Nativo)';
3
Paste and Execute

Paste the SQL in the Supabase SQL Editor and click Run (or press Cmd/Ctrl + Enter)

4
Verify Success

You should see a success message. The column is now ready to use!

✅ After Migration: Candidates will be able to submit applications with their English level. The application form will work correctly.

🔍 Verify Migration (Optional)

After running the migration, you can verify it was successful with this query:

-- Verify nivel_ingles column exists
SELECT column_name, data_type, is_nullable
FROM information_schema.columns
WHERE table_name = 'aura_jobs_candidatos'
AND column_name = 'nivel_ingles';
